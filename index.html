Set up song search (one time, free)
  1. Open console.cloud.google.com and sign in with your Google account.
  2. Create a project. Any name works.
  3. Search for YouTube Data API v3 and tap Enable.
  4. Open Credentials, tap Create credentials, then API key, and copy it.
  5. Recommended: edit the key, add the website under website restrictions, and limit it to the YouTube Data API v3.
  6. Paste it here and tap Save.

The key stays on this phone. The free allowance covers about 100 searches a day.
